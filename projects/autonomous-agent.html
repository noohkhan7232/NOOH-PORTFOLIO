Project Overview & Core Problem

Exploratory Data Analysis (EDA) and preliminary machine learning benchmarking often consume days of manual data wrangling. Data analysts and scientists spend significant time writing repetitive scripts for missing value imputation, distribution plotting, correlation matrix extraction, and model selection.

The Agent Solution: This project implements an autonomous unified reasoning agent. By pairing Large Language Model (LLM) reasoning loops with deterministic Python data execution environments, the agent accepts raw CSV/Parquet files, formulates analytical questions, executes code securely, interprets outputs, and presents synthesized findings in clean Markdown/HTML reports.

Key Features & Workflow Capabilities

  • Autonomous Data Profiling: Automatically inspects data types, missing value ratios, cardinality, and skewness across all columns.
  • Reasoning-Guided Feature Engineering: Generates domain-informed feature transformations based on column semantics rather than blind mathematical operations.
  • Automated Model Tournament: Trains and evaluates multiple baseline models (Random Forest, Gradient Boosting, Logistic Regression, Linear Models) with cross-validation.
  • Natural Language Querying: Allows users to ask conversational questions like "What factors drive customer churn in this dataset?" and returns code-backed evidence.
  • Self-Correction Code Execution: Catches Python execution errors during runtime and uses the LLM error traceback to iteratively fix and re-run analysis code.

Technologies & Concepts Learned
