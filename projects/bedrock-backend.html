Project Overview

Integrating Large Language Models directly into web applications requires server-side middleware to protect cloud API credentials, manage rate limits, format prompt templates securely, and handle Server-Sent Events (SSE) token streaming for responsive frontends.

The Solution: Built a production-ready Python backend using FastAPI and `boto3`. The service abstracts AWS Bedrock API calls behind clean REST endpoints, validates payload structures with Pydantic v2, streaming responses byte-by-byte to client clients, and enforcing security policies.

Key Backend Capabilities

  • Server-Sent Events (SSE) Streaming: Returns LLM output chunks asynchronously as they are generated by AWS Bedrock runtime.
  • Dynamic Model Switcher: Allows clients to toggle between foundation models (e.g. Claude 3, Titan Text) via structured query parameters.
  • Pydantic Payload Guards: Prevents malformed prompt injection by validating strict schema contracts before reaching external APIs.
  • Asynchronous AWS Boto3 Execution: Offloads synchronous Boto3 network calls to background threadpools using `anyio.to_thread`.
  • Dockerized Microservice: Packaged into a lightweight Alpine-based container ready for ECS / EKS deployment.
