Project Overview & Objectives

Understanding low-level hardware abstraction and operating system mechanics is essential for building high-efficiency backend services. Developers who understand how OS kernels allocate memory, manage process context switches, and handle cache thrashing write significantly more performant production backend code.

The Project: Mem-Forge OS simulates an operating system kernel's core subsystems in code. It implements custom memory allocators (First-Fit, Best-Fit, Buddy System), simulates virtual memory paging with Least Recently Used (LRU) / FIFO page replacement, and models CPU process control blocks (PCB) with Round-Robin scheduling.

Key Low-Level Features

  • Virtual Memory Paging Engine: Translates virtual addresses to physical frame offsets with page table lookup simulations.
  • Page Fault & Eviction Benchmarker: Compares LRU, FIFO, and Optimal page replacement algorithms under thrashing workloads.
  • Dynamic Memory Allocator: Simulates heap memory fragmentation, compaction, and block splitting/coalescing algorithms.
  • Process Scheduler & Context Switching: Simulates state transitions (Ready, Running, Blocked, Terminated) across processes with CPU time quantum slicing.
